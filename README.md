# LightGlow: Fast

A very lightweight shader for Minecraft Java 26.3 — made for low-end PCs.

**What you get**
- 🔥 Warm, brighter torches (adjustable)
- 🌑 Softer, cooler shadows with warm sunlight
- 🧍 Pixelated player-silhouette shadow
- 🌫️ Two moods: **Dark** (horror-like) and **Eclipse**
- 🌊 Wavy, transparent water with sky reflection and sun glint
- 🌧️ Wet blocks and pixelated puddles when it rains

**Why it's fast**
No post-processing passes: everything is done with cheap math in the block shaders. The only extra pass is a tiny shadow map that holds just the entities.

**Requirements:** Minecraft Java 26.3 + Iris (and Sodium).

**Install:** put the .zip in `shaderpacks` (don't extract) → press **I** in game.

**Tips**
- Too dark? Lower *Atmosphere strength*.
- Two player shadows? Turn off *Entity Shadows* in video settings.

Bug reports are welcome — please include your Iris log.
